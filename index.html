Installing

On a Mac

  1. Open the .dmg and drag Design app into Applications.
  2. Open Design app. The first time, macOS says it can’t check the app for malware, because it isn’t notarized by Apple yet. Click Done.
  3. Open System Settings, go to Privacy & Security, and click Open Anyway next to the message about Design app.

If macOS says the app is damaged, run this in Terminal, then open it again:

xattr -dr com.apple.quarantine "/Applications/Design app.app"

On Linux

On Debian, Ubuntu and their derivatives, install the .deb. It adds Design app to your app menu and design-app to your PATH.

sudo apt install ./design-app-0.2.0-linux-amd64.deb

On any other distribution, make the AppImage executable and run it:

chmod +x design-app-0.2.0-linux-x86_64.AppImage
./design-app-0.2.0-linux-x86_64.AppImage

On Ubuntu 24.04 and later, the AppImage may need --no-sandbox to start. The .deb doesn’t.

What it needs

  • Claude Code, installed and signed in. The agents run on it.
  • Chrome or Chromium, to take screenshots of your designs.
  • To share a design at a link anyone can open: the GitHub CLI, signed in with gh auth login. Shared designs go on GitHub Pages, in a public repository on your account.

On Linux, Design app updates itself. On a Mac, it tells you when a new version is out, and you download it here.
